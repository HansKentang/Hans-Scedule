## Rhythm page — bug fixes and visual polish (second pass)
Hans: "it has bugs pls fix it make it nicer". Found the bugs by actually rendering the page, not by guessing.

**Method that worked (reusable):** Playwright's Chromium binary was already on the machine at `C:\Users\ASUS\AppData\Local\ms-playwright\chromium-1228\chrome-win64\chrome.exe`. `npm install agent-browser` failed (network), but Chromium alone is enough:

- Rendered DOM: same but `--dump-dom` instead of `--screenshot` — this is how the i18n bug was caught.
- **`--user-data-dir` hangs in this environment — avoid it.** Also keep each run in its own Bash call; chaining several chromium invocations in one command hits the timeout.

**Bugs found and fixed:**
1. **Auth guard missing (mine, and serious).** Every page has `<script>document.addEventListener('DOMContentLoaded', initGSI);</script>`. `initGSI()` in `js/gsi.js` redirects to `login.html` when there is no active user. `rhythm.html` lacked that line, so the page was reachable without signing in. Added. Verified: signed out, `rhythm-q-title` count is 0 and the login page renders.
2. **`.hub-footer` / `.hub-footer-inner` don't exist** in the CSS. The real class is `.hub-minifooter` + `.hub-minifooter-actions`. Footer was rendering unstyled.
3. **"Next" button stranded on the left** — `justify-content: space-between` with the Back button hidden. Fixed with `margin-left: auto` on the primary button.
4. **Pre-existing i18n bug, affects the whole app.** `_ENG_TXT` maps `'Start'` → `'common.start'`, but no such key exists in `LANG`, so `t()` returns the key and the user sees **"common.start over"**. `tStr()` does a prefix match, so *any* string beginning with "Start" gets mangled — including the timer's Start button. Fixed at the root: `tStr()` now detects a raw-key result and falls back to the original English. This fixes every broken `_ENG_TXT` entry at once.
5. **Mobile bottom nav overflow (pre-existing).** `.hub-mobile-bottom-nav` had no overflow handling; 7 items already exceeded 390px, and Rhythm made it 8. Added `overflow-x: auto` + hidden scrollbar and `flex: 0 0 auto` on items.
